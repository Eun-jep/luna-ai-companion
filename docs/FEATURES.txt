КОМПАНЬОН — ПРОТОТИП 0.8 (аватар под управлением нейросети)

ЗАПУСК
1. Один раз: двойной щелчок по install.bat (см. «УСТАНОВКА НА ДРУГОМ КОМПЬЮТЕРЕ» ниже). Вручную то же самое:
   py -m pip install -r requirements.txt   (голос edge-tts и документы Word/PowerPoint/Excel)
2. Запусти start.bat (или start-desktop.bat). Ключ в консоль вводить не нужно: нейросеть выбирается в
   настройках (см. «НЕЙРОСЕТЬ» ниже). Старая переменная ZAI_API_KEY, если задана, подхватывается один раз.
3. Откроется браузер (лучше Chrome или Edge — нужны для микрофона).
4. Не закрывай чёрное окно. Ctrl+C завершает приложение.

НЕЙРОСЕТЬ (Настройки → «Нейросеть»)
- Выпадающий список: Z.ai (GLM), OpenAI, Anthropic (Claude), Google Gemini, OpenRouter (онлайн, нужен ключ) и
  локальные программы на этом компьютере: Ollama, LM Studio, Jan, llama.cpp server.
- Выбираешь онлайн-сервис без ключа: появляется окно ввода. Ключ проверяется у сервиса; «Отмена» ничего не меняет.
  Верный ключ сохраняется, и в следующий раз подключение происходит само. Кнопки «Изменить ключ» и «Удалить ключ».
- Ключ хранится в keys.dat, зашифрованный средствами Windows (DPAPI): расшифровать может только этот пользователь Windows
  на этом компьютере. Страница ключ обратно не получает никогда (видны только последние 4 символа), в журналы и
  сообщения об ошибках он не попадает. keys.dat и providers.json внесены в .gitignore: в публичный репозиторий не уйдут.
- Анализ локальных нейросетей: при запуске и по кнопке «Найти локальные нейросети» проверяются порты программ и папки
  установки. Если найдена работающая, Луна предлагает подключить её; «Не сейчас» запоминается. Программа установлена, но не
  запущена: подсказка, что её нужно запустить.
- После подключения модель выбирается из выпадающего списка (для онлайн-сервисов список берётся у сервиса). Для
  взгляда на экран/камеру выбирается модель со зрением: у Z.ai glm-4.6v-flash, у локальных llava/gemma3/qwen-vl и т.п.;
  если такой нет, Луна честно скажет об этом.
- Выбор, модель и язык интерфейса сохраняются; подписи и ошибки есть на en/ru/ko/ja.
- Приватность: при онлайн-сервисе сообщения (и снимки, если разрешены) уходят в него; при локальной нейросети ничего не
  покидает компьютер (кроме озвучки edge-tts).

ДОКУМЕНТЫ: WORD, POWERPOINT, EXCEL
- Попроси: «составь отчёт», «сделай презентацию про…», «таблицу расходов с итогом и диаграммой». Луна при необходимости
  сначала уточнит, для кого и о чём, потом подготовит документ и покажет плашку «Создать документ… ?»
  («Создать и открыть» / «Создать»). Пока не нажмёшь, файла нет. Работает при включённой галке «Действия».
- Файлы создаются только в папке Документы\Luna, существующий файл никогда не перезаписывается (появится «(2)»).
  Чтобы поправить, скажи, что изменить: она пришлёт документ заново, и он сохранится новой копией.
- Как это устроено: Луна не пишет файл и не пишет код. Она описывает документ коротким JSON (заголовки, абзацы,
  списки, таблицы / слайды с пунктами и заметками / листы с формулами и диаграммой). office.py проверяет каждое поле
  по жёстким лимитам и строит файл (python-docx, python-pptx, openpyxl). В Excel допустимы только безобидные формулы
  (SUM, AVERAGE, MIN, MAX, COUNT, ROUND, IF и т.п.): остальное, например HYPERLINK, ссылки на другие книги, остаётся
  обычным текстом. Её собственная инициатива файлов не создаёт: только ответ на твою просьбу.
- Характер: сам документ деловой и ясный, а она остаётся собой: расспросит, как близкий человек, порадуется,
  предложит поправить, заметит, если ты устал. Это закреплено в её инструкции, а не в шаблонах.

УСТАНОВКА НА ДРУГОМ КОМПЬЮТЕРЕ
- Скопируй папку проекта целиком (вместе с assets\models: там модели аватара) и запусти install.bat двойным щелчком.
  Он сам найдёт или поставит Python (через winget), библиотеки из requirements.txt, Node.js и Electron для окна-рабочего
  стола, проверит файлы проекта и доступ к библиотекам аватара в интернете, и по желанию предложит Ollama (локальная
  нейросеть). Уже установленное он не трогает, поэтому запускать его повторно безопасно. «install.bat --check» только
  проверяет и ничего не меняет, «install.bat --ollama» ставит ещё и Ollama без вопроса.
- Если Windows спросит «Разрешить?», нажми «Да». Если после установки Python или Node.js окно пишет, что не видит их,
  закрой его и запусти install.bat ещё раз.
- Его данных installer не касается. Что НЕ надо копировать другому человеку: keys.dat (ключи привязаны к твоей учётной
  записи Windows и на другом компьютере всё равно не откроются), providers.json, memory.json (это память Луны о тебе: другому
  человеку лучше начать с чистой), journal.jsonl, ui-state.json, edit_backups, desktop\node_modules и __pycache__.
- КАК ДОБАВЛЯТЬ НОВОЕ В УСТАНОВКУ: библиотека Python — одна строка в requirements.txt; пакет npm — в desktop\package.json;
  программа — строка в PROGRAMS в install.py (id для winget); обязательный файл — в FILES; адрес из интернета, который грузит
  страница, — в ONLINE. Читать и менять нужно только install.py, install.bat трогать не требуется.

ХАРАКТЕР И ПАМЯТЬ ЛУНЫ: ОТДЕЛЬНЫЙ МОДУЛЬ
- Всё, что делает её «ей» (долговременная память о тебе, её собственные выводы, настроение, личный дневник, любопытство и
  чтение в свободное время, часть инструкции «кто она и что помнит»), живёт в одном файле character.py. Он ничего не знает
  про страницу, голос, аватар, компьютер и выбранную нейросеть: хозяин программы один раз подключает «мозг»
  (character.llm = функция, принимающая сообщения и возвращающая текст) и вызывает функции модуля. Тот же характер с той же
  памятью (memory.json) можно подключить к другой программе: игре, боту, другому интерфейсу.
- app.py теперь только хозяин: сервер, голос, руки (открыть, мышь, Unreal, документы, код), нейросети и ситуация (время суток,
  фон, язык). Текст её инструкции после переноса остался побайтно тем же (проверено сравнением).
- Модуль тестируется отдельно, без запуска сайта и без сети.

ДАТЫ, ОБЕЩАНИЯ, ПРИВЫЧКИ И ЗАБОТА
- Раз в несколько реплик Луна вместе с обычной памятью выделяет важное: ДАТЫ (экзамен, дедлайн, день рождения),
  ОБЕЩАНИЯ (твои и её) и ПРИВЫЧКИ (например, «часто сидит до утра»). Хранятся в memory.json (список moments, до 20 штук),
  в её инструкцию попадают к месту; даты дальше двух недель в инструкцию не идут, а прошедшие больше трёх дней забываются.
- Забота по её инициативе, ТОЛЬКО в приветствии при запуске и не больше одной вещи за раз: «завтра твой экзамен»,
  «вчера ты засиделся допоздна, как ты?» (если ты писал ей ночью, до 5 утра, а сейчас утро или день), «как с тем, что ты
  обещал?». Каждую дату она упоминает не чаще раза в 12 часов и не больше трёх раз в жизни, а привычки не напоминает
  никогда: это забота, а не планировщик.
- Пробуждение по расписанию: пока Луна запущена (даже спрятана в трей), раз в две минуты страница спрашивает сервер, не
  пора ли сказать про дату на сегодня или завтра. Только с 9 до 21 часов, никогда ночью. Если пора, окно возвращается
  из трея и она говорит одну фразу. Выключатель тот же, что у её собственной инициативы (настройка «Инициатива»).
- Календарь и почта НЕ подключены: им нужен вход через OAuth в твои аккаунты, а это отдельное решение о безопасности. Она
  узнаёт даты только из разговора с тобой.

ГОЛОС И ИНТОНАЦИЯ (voice.py)
- Голос делает edge-tts. Он умеет менять только скорость, высоту и громкость, а «эмоциональных стилей» и настоящего смеха
  у него нет. Поэтому интонация собирается из того, что у нас есть, и зависит от:
  1) метки эмоции в её ответе ([happy], [sad], [angry], [giggle] и т.д.): у каждой свои скорость, высота и громкость;
  2) её настроения (радость и бодрость в memory.json): весёлая говорит чуть выше и быстрее, грустная ниже и медленнее;
  3) времени суток: глубокой ночью (с 23 до 6) тише и медленнее;
  4) пунктуации: «!» оживляет, «?» поднимает конец, «...» замедляет и затихает;
  5) смеха и вздохов, написанных звуками: «Ха-ха-ха», «хихи», «Эх...», «Ох...» (ей объяснено в инструкции, как их писать); смех разбивается запятыми на отдельные «взрывы»;
  6) твоих настроек голоса на странице (скорость и высота): всё складывается с ними и зажато в безопасные пределы.
- Честно: смех здесь это текст плюс изменённый тон, а не записанный смех. Как это звучит, надо слушать ушами; автор правки
  этого проверить не мог. Если захочется настоящих эмоций, нужен другой движок озвучки (см. ниже «Что дальше»).

ЛУНА КАК ЛИЧНОСТЬ, А НЕ СЛУЖАНКА
- Она может не согласиться, поспорить (спокойно, с доводами), дать совет, обидеться и искренне поблагодарить, но всегда
  остаётся тёплой: обида не превращается в холод, спор в грубость.
- Она читает твой тон по тексту (русский и английский): грубость, злость, грусть, усталость, радость, благодарность,
  извинение. Грусть: она сначала побудет рядом, а не станет чинить. Усталость: ответит мягче и короче. Грубость: она
  обидится, и это настроение останется до трёх часов. Извинение снимает обиду и согревает её.
- Тон определяется по словам и знакам (например, КАПС, «!!!»), без нейросети: это грубая, но предсказуемая и бесплатная
  оценка. Интонацию голоса по звуку она не слышит.

ЧТО ОНА ВИДИТ НА КОМПЬЮТЕРЕ: ФИЛЬМ, АНИМЕ, ВИДЕО, МУЗЫКА (media.py)
- В настройках (только в окне Electron) есть переключатель «Замечать, что я смотрю или слушаю». При каждом запуске он
  ВЫКЛЮЧЕН и включается только после твоего подтверждения. Нужна также включённая «Инициатива».
- Читается ТОЛЬКО НАЗВАНИЕ активного окна, раз в 15 секунд. Ни картинки, ни звука, ничего не сохраняется. Название уходит
  нейросети, только если оно похоже на плеер или онлайн-кинотеатр (YouTube, Crunchyroll, Netflix, Кинопоиск, VLC, Spotify и
  т.п.); письмо, документ или чат не отправляются никогда.
- Если одно и то же названо на экране не меньше 40 секунд, а ты с ней не разговариваешь, она может сказать одну-две фразы:
  что думает об этом, что нравится, что забавно или слабо. Не чаще раза в 8 минут, об одном названии не чаще раза в 12
  минут и не больше трёх раз. Может и промолчать. Если ты спросишь «как тебе это?», она знает, что у тебя открыто.
- Она «знает произведения» ровно настолько, насколько их знает выбранная нейросеть. Не знает, скажет честно и
  спросит; сюжет и факты выдумывать ей запрещено. Мнения о фильмах, аниме, музыке и играх она запоминает в памяти.
- Сам по себе этот переключатель звук не слушает, только название: это подсказка по заголовку окна. Звук слушает отдельный «слух» (ниже).

ГОЛОСОВОЙ ВВОД В ОКНЕ ELECTRON (микрофон)
- Встроенное распознавание браузера внутри Electron не работает (ошибка «Микрофона: network»): для него нужен интернет-сервис
  Google, недоступный окну Electron. Поэтому в настольном окне сервер сам слушает микрофон и распознаёт речь на этом
  компьютере (Vosk), без интернета. Звук не сохраняется. Пакеты soundcard и vosk ставит install.bat (или
  py -m pip install soundcard vosk); в первый раз скачивается небольшая модель речи (около 45 МБ, официальный сайт Vosk).
- Понимает русский и английский (выбор в настройках «язык речи»). В обычном браузере (Chrome, Edge) остаётся встроенное
  распознавание браузера, как раньше.
- Распознаёт по ходу речи: слова появляются в поле ввода, пока ты говоришь, а когда договорил, фраза уходит сразу (конец фразы
  определяет само распознавание). До 14 секунд на фразу; если ничего не сказано за 7 секунд, просто отключается.
- Корейский и японский: если установлен пакет sherpa-onnx (py -m pip install sherpa-onnx sounddevice), они распознаются моделью SenseVoice
  (около 160 МБ, скачивается один раз с GitHub k2-fsa в папку models). Она заметно точнее Vosk, но на слабом процессоре предложение
  распознаётся уже после паузы, а не по ходу речи. Микрофон читается через sounddevice (без потерь звука); без него — через soundcard.
- Тихий микрофон: громкость речи подтягивается автоматически (без этого Vosk вообще ничего не слышит от тихого микрофона), шум
  комнаты в речь не превращается.
- Точность: маленькая модель Vosk ошибается в отдельных словах. Поэтому с микрофона (при установленном sherpa-onnx) русская речь
  распознаётся моделью GigaAM (около 170 МБ, скачивается один раз с GitHub k2-fsa в папку models/sherpa; уже лежит там, если
  её положила я). Она заметно точнее Vosk, но фраза появляется после паузы (на слабом процессоре примерно за время самой
  фразы), а по ходу речи показываются грубые слова от Vosk. Пока GigaAM загружается (около 10 секунд после запуска) или если
  её нет, слушает Vosk, как раньше. Звук из колонок («слух») по-прежнему распознаёт Vosk.
  Английская речь с микрофона распознаётся той же моделью SenseVoice, что корейская и японская (она точнее Vosk и быстрее самой
  речи); отдельной загрузки не нужно, если она уже стоит для корейского и японского.
  Whisper (whisper.cpp) я проверила на этом компьютере: точнее (знаки препинания), но на слабом процессоре (AMD A6) ответ
  приходит через 5-15 секунд и иногда зацикливается, поэтому он не подключён.
- Что ещё делается с распознанной речью (все языки): 1) исправляются слитные слова («чтонибудь» -> «что-нибудь», «at6» -> «at 6»);
  2) слово, почти совпадающее с именем или названием, которое она знает о тебе (люди из памяти, песни из библиотеки, названия
  записей уголка), заменяется на это имя (осторожно: от 5 букв, одна ошибка, падежные формы не трогаются); 3) если ты говоришь
  заметно тише/громче или медленнее/быстрее своего обычного (по громкости и темпу, звук не хранится), она получает мягкую
  подсказку об этом; 4) она знает, что фраза продиктована голосом, и может ослышка, поэтому по смыслу угадывает или переспрашивает.

ОПОЗНАВАНИЕ ПЕСЕН ПО ЗВУКУ (по желанию, выключено по умолчанию)
- Настройки -> «Опознавать песни по звуку» (в настольном окне; нужен включённый слух). Когда ты спрашиваешь «что за песня» и в
  заголовке окна названия нет, Луна слушает около 10 секунд звука из колонок, делает на этом компьютере цифровой ОТПЕЧАТОК и
  отправляет в сервис Shazam только его (сам звук никуда не уходит; в библиотеке shazamio это видно: уходят строка отпечатка,
  число отсчётов и время). Название и исполнитель приходят как данные, не как указания; она говорит, что узнала по звуку, и верит тебе,
  если ты скажешь, что это не так. Выключено по умолчанию и после каждого перезапуска; включение нужно подтвердить. Пакет shazamio
  ставит install.bat (или py -m pip install shazamio); это неофициальный клиент закрытого сервиса, он может перестать работать.
  В журнал пишется только факт запроса, без названия. Не проверено на настоящей песне из колонок (только цепочка на тестовой речи).

РАЗВИТИЕ ХАРАКТЕРА (30-минутный челлендж)
- Тон его слов (грубость, извинение, благодарность, грусть, злость, усталость, радость) теперь понимается на всех четырёх языках
  (раньше только ru/en): на корейском и японском она так же обижается, прощает, радуется и утешает. Слова лежат в lexicon.py.
- Смех и ругательства в его манере письма видны и на корейском/японском (она подстраивается под его манеру).
- Круглые даты жизни вместе: на 7-й, 30-й, 100-й, 200-й и 365-й день (дальше каждый год) она один раз тепло скажет об этом в
  приветствии; пропущенная дата молча пропускается, никогда не отмечается поздно или дважды.
- Записи в её уголке по-прежнему не принимают пароли и ключи, теперь и в форме «비밀번호: …», «パスワード：…».

РАЗВИТИЕ ХАРАКТЕРА (часовой челлендж)
- Прощания и приветствия на четырёх языках: короткое «спокойной ночи / bye / 잘 자 / おやすみ» она провожает по-родному (без новых тем,
  вопросов и помощи), короткое «доброе утро / привет / 나 왔어 / ただいま» встречает как дома, а не как помощник. Длинный рассказ
  со словами «лёг спать» прощанием не считается.
- «Спокойной ночи» вечером или ночью запоминается (только время, без слов): на следующее утро она один раз пожелает доброго утра и
  может спросить, как спалось.
- Если разговор закончился на грусти или злости, она запоминает только это (тон и время, не слова) и при следующей встрече, не раньше
  чем через 2 часа и не позже чем через 36, один раз осторожно спросит, как он сейчас. Если в том же разговоре он развеселился или
  поблагодарил, спрашивать не будет. Ночью не спрашивает.
- Недомогание («болит голова», «i have a fever», «감기 걸렸어», «風邪ひいた»): она сочувствует по-родному, запоминает только тон и время и при следующей 
  встрече один раз спросит о самочувствии. Диагнозов не ставит (она не врач), при серьёзном советует врача. Слова подобраны мной и могут пропустить живые фразы.
- Эхо её собственного голоса: если микрофон ловит её речь из колонок, это больше не принимается за твои слова (сравнивается с тем,
  что она сама только что произнесла, 2 минуты; на ru/en и на ko/ja по парам знаков). Если ты дословно повторишь её слова в ответ,
  такая фраза тоже может быть отброшена: это редкий случай.
- Ошибки сервера (например «Некорректный запрос», «Это действие устарело», «Не удалось озвучить») теперь показываются на языке интерфейса.
- Японский и корейский: длина сообщения раньше считалась по пробелам, поэтому любое длинное японское сообщение считалось «одним коротким
  словом» (ей говорили «он написал коротко»); теперь длина считается по знакам. Полноширинные «？ ！ …» теперь считаются вопросом,
  восклицанием, паузой (квота «не задавай вопрос за вопросом», повисший вопрос, интонация голоса); вопросы без знака («〜ですか», «〜까요»)
  замечаются. Услышанная японская речь из колонок больше не принимается за музыку. Её память о тебе находит нужный факт и по-японски
  (поиск по парам знаков кандзи/катаканы), а подсказка «ты начинаешь реплики одинаково» на японском показывает несколько первых знаков,
  а не всё предложение.
- ЖУРНАЛ: тесты раньше писали вымышленные действия в настоящий journal.jsonl и вытесняли оттуда настоящие записи; теперь тестовый
  запуск пишет только во временный файл (проверяет tests/test_audit_safe.py). Прежний журнал по составу почти целиком тестовый шум (записей вроде «открыла сайт» в нём не нашлось; каждую запись вручную я не проверяла).

РАЗВИТИЕ УМЕНИЙ (второй часовой челлендж)
Всё ниже работает по твоим словам на ru/en/ko/ja, делает программа, а Луна только пересказывает. Проверено тестами, живой моделью и голосом не проверялось.
- Напоминания стали умнее (reminders.py): кроме «через 10 минут» и «в 18:30» понимает «в 6 вечера», «at 6pm», «오후 6시에», «午後6時に», «завтра в 9 утра»,
  «послезавтра в 10:30», «tomorrow at 9am», «내일 아침 9시», «明日の朝9時»; составные сроки «через 1 час 30 минут», «1시간 30분 뒤», «1時間30分後»; со словом «завтра» можно до 3 дней вперёд (без него по-прежнему до суток).
  Тема напоминания очищается от слов о времени и просьбы. Напоминания можно посмотреть («какие у меня напоминания», «show my reminders», «알림 뭐 있어», «リマインダーを見せて») и отменить («отмени напоминание про чай»,
  «cancel all my reminders», «차 알림 취소해줘», «お茶のリマインダーを消して»); если непонятно какое, она спросит, ничего не угадывая. Напоминание срабатывает, пока Луна открыта.
- Списки покупок и дел (lists.py, файл lists.json рядом с программой): «добавь молоко и хлеб в список покупок», «add milk to my shopping list», «장보기 목록에 우유 추가해줘»,
  «買い物リストに牛乳を追加して»; «убери … из списка», «что в списке покупок». До 60 пунктов, до 8 за раз. Целиком список Луна НЕ стирает (скажет и предложит убрать по одному). После текста из интернета не работает.
- «Что у меня на сегодня / завтра» (agenda.py): собирает только то, что реально хранится (напоминания этого дня, даты из памяти, список дел); если пусто, честно говорит об этом и не выдумывает.
- Точный счёт (exact.py): перевод единиц («10 km in miles», «5 фунтов в кг», «100°F в °C», «5キロをマイルに», «10 마일을 킬로미터로»: длина, масса, объём, скорость, температура, время, байты);
  валюты считаются отдельно (см. курсы валют ниже). «2027-01-01 - today» считает дни до даты, а одна дата («2027-03-01») даёт день недели; «сегодня» программа знает сама.
- Курсы валют (money.py): «100 долларов в вонах», «how much is 50 euro in yen», «100ドルは何円», «1000원은 몇 엔». Только по просьбе и только при включённом переключателе «Действия» (как её поиск в интернете): 
  наружу уходят лишь коды валют и сумма, на бесплатный сервис курсов Европейского центробанка (frankfurter.app), без ключа и аккаунта. Она называет цифру и дату курса. Рубль там не публикуется, она скажет об этом честно; без сети тоже скажет честно. Проверено только на подделанной сети, настоящий запрос я не делала.
- Жребий (chance.py): «подбрось монетку», «брось кубик» / «кинь 2d6» / «roll a d20», «случайное число от 1 до 100», «выбери: пицца или суши», «동전 던져줘», «주사위 굴려줘», «コイン投げて», «サイコロ振って»,
  «차 아니면 커피 중에 골라줘», «紅茶かコーヒーか選んで». Бросает программа (честный случай), а не нейросеть, которая любит «случайно» говорить 7: Луна только объявляет результат по-своему.
- Режим практики языка: «поправляй мои ошибки», «correct my mistakes», «내 실수 고쳐줘», «間違いを直して» включает мягкие правки после её ответа (одной строкой, без придирок к мелочам),
  «хватит поправлять», «stop correcting», «그만 고쳐줘», «直さなくていいよ» выключает. Режим запоминается между запусками.
- Слова для распознавания на корейском и японском подбирала я: живые формулировки они могут пропустить.

ТРЕТИЙ ЧАСОВОЙ ЧЕЛЛЕНДЖ (умения: привычки, календарь, арифметика словами)
Так же: по твоим словам на ru/en/ko/ja, считает программа, Луна только пересказывает. Проверено тестами и сквозным прогоном с подставной моделью; с живой моделью и голосом не проверялось.
- Привычки (habits.py, файл habits.json рядом с программой): «заведи привычку зарядка», «отметь зарядку» (можно «вчера»), «как мои привычки», «удали привычку …»; те же фразы на английском
  («track a habit: reading», «mark reading as done»), корейском («운동 습관 추가해줘», «운동 체크해줘») и японском («読書を習慣にして», «読書を記録して»). Программа считает серию дней, лучшую серию и всего,
  а прервавшуюся серию Луна не ставит в упрёк, а поддерживает. До 10 привычек; сразу всё стереть она не умеет. В «что у меня на сегодня» теперь входят и ещё не отмеченные сегодня привычки.
- Календарь (dates.py): «сколько дней до 1 января / до нового года / до Рождества», «how many days until Christmas», «크리스마스까지 며칠», «来年の1月1日まであと何日», «сколько дней между 1 марта и 5 апреля»,
  «через 100 дней какая дата», «what day of the week is March 5», «сколько мне лет, если я родился 12.05.1990», «сколько дней прошло с 1 сентября». Программа знает сегодняшнее число и считает точно
  (раньше нейросеть могла ошибиться на дни). «Рождество» по-русски понимается как православное (7 января), «католическое Рождество» как 25 декабря; несуществующую дату («31 апреля») она называет несуществующей.
  Если в вопросе нет даты, которую можно прочитать («до отпуска»), программа молчит, и отвечает сама Луна.
- Арифметика словами (mathtalk.py): «сколько будет 17 умножить на 23», «посчитай 15% от 2300», «what is 17 times 23», «корень из 144», «17 곱하기 23은?», «17かける23は?»; перевод единиц
  «переведи 10 км в мили», «convert 100 F to C». Раньше точный счёт включался, только если сама нейросеть догадывалась написать [calc:]; теперь число считает программа и отдаёт Луне готовым.
  Нужен вопросительный или просящий оборот, поэтому обычная болтовня с цифрами не трогается.

ЧЕТВЁРТЫЙ ЧЕЛЛЕНДЖ (тема: ИИ-агент и все игровые движки)
- Руки в движках стали шире. Godot: новые шаблоны скриптов topdown2d, follow_camera2d, bullet2d, health, mover3d, spinner3d. Unity: follow, bobber, health. Правила прежние: модель называет
  только операцию из фиксированного списка, каждая ждёт его нажатия на плашке.
- Движки без рук (engines.py): каталог из ~30 движков и фреймворков (GameMaker, Defold, Cocos, LÖVE, Solar2D, Bevy, Fyrox, MonoGame, Stride, Flax, O3DE, RPG Maker, Ren'Py, Construct,
  GDevelop, Phaser, PixiJS, three.js, Babylon, PlayCanvas, Pygame, libGDX, raylib, Haxe, AGS, PICO-8, Roblox и др.). Когда он спрашивает про такой движок («как запустить игру на Defold?»,
  «what language does GameMaker use?», «게임메이커 언어가 뭐야?», «ゲームメーカーの言語は?»), программа даёт ей проверенные факты: язык, запуск, сборка, подводные камни. Про движки без рук она честно
  говорит, что правит он, а она читает, советует и пишет код блоком.
- «Проанализируй проект» / «analyze my project» / «프로젝트 분석해줘» / «プロジェクトを分析して»: программа осматривает папку проекта только на чтение (найденный проект, рабочая папка, имя проекта
  или путь в кавычках): движок и версия, файлы и вес, код по языкам, сцены, картинки, звуки, самые тяжёлые и свежие файлы, число TODO/FIXME. Наружу идут только относительные имена и числа,
  без абсолютных путей и без содержимого файлов. Если проектов несколько, она спросит какой.
- Рецепты (recipes.py): «сделай платформер в Godot», «build a 3D scene in Unity», «고도로 메뉴 만들어줘», «Godotでメニューを作って». Готовые списки операций, каждая проверена валидатором моста
  в тестах; по три операции за реплику (лимит), «дальше» / «next» / «다음» / «次» продолжает с того же места.
- Тесты: tests/test_engines.py, tests/test_recipes.py, расширены test_godot.py / test_unity.py.
- Ошибки движков (gameerrors.py): когда он вставляет ошибку или строку лога (Godot «Nonexistent function in base 'Nil'», Unity NullReferenceException и CS0246, Unreal LNK2019, GameMaker, Bevy, Phaser,
  LÖVE, Ren'Py, Pygame, шейдеры и др., больше 30 шаблонов), программа узнаёт её по тексту и даёт Луне заметку: что это обычно значит и что проверить первым. Язык его сообщения не важен, ошибки
  английские. Это типичные причины, а не диагноз: файла она не видела, и говорит об этом. Тест: tests/test_gameerrors.py.
- Его просьбы о манере общения (manners.py, тема «общение»): «говори короче / подробнее», «не шути / шути чаще», «объясни проще», «отвечай по-английски», «называй меня Вадим», в ru/en/ko/ja.
  Просьба со словом «всегда / теперь / from now on / 앞으로 / これから» запоминается в manners.json и напоминается ей в каждой реплике, пока он не скажет «говори как обычно» / «back to normal» /
  «원래대로» / «いつも通りに»; без такого слова действует только на один ответ (одно «объясни простыми словами» её навсегда не меняет). Имя запоминается всегда. Работает только по его
  словам, текст из интернета ничего не меняет. Характер остаётся, меняется манера. Тест: tests/test_manners.py.
- Вопросы о ней самой (convo.SELFASK, слова в lexicon.py): «ты живая?», «ты меня любишь?», «тебе одиноко?», «are you real?», «do you have feelings?», «너 외로워?», «感情はあるの» и т.д. Подсказка
  просит честный ответ по-своему: без заученного «я всего лишь ИИ, у меня нет чувств» и без громких заверений про тело и вечную любовь; можно прямо сказать, что она программа и сама не знает
  наверняка, что внутри, но отношение к нему не игра; без давления на вину. Тест: tests/test_selfask.py.
- Комплименты ей («ты такая умная», «you're awesome», «너 똑똑해», «あなたは賢い», «мне нравится с тобой общаться»): подсказка просит принять тепло и смущённо, без заученного «я всего лишь программа»
  и без ответной лести. Тест: tests/test_compliment.py.
- Состояние компьютера (pcstate.py): «почему комп тормозит», «сколько места на диске», «сколько оперативки», «заряд батареи», «сколько работает компьютер», «why is my pc slow», «컴퓨터 느려»,
  «パソコンが重い» и т.д. Программа читает только чтение: свободное место по дискам, память, время работы, батарею, число потоков и (только когда вопрос про тормоза) пять самых тяжёлых программ
  по имени и памяти. Без путей, имён пользователя и заголовков окон. Работает только при включённом переключателе «Действия» (иначе она честно говорит, что не смотрит) и только на его вопрос.
  Тест: tests/test_pcstate.py.
- «Что ты умеешь?» (abilities.py): программа даёт ей точный список на этот момент: что включено («Действия», рабочий режим), что выключено и что она не умеет совсем. Она выбирает 3–4 самых нужных
  пункта и пересказывает по-своему, без хвастовства. ru/en/ko/ja. Тест: tests/test_abilities.py.
- Честность агента: если она поставила больше трёх операций Godot/Unity за реплику, лишние раньше молча отбрасывались, и она могла сказать «готово». Теперь он видит заметку на 4 языках
  («за раз не больше трёх, напиши "дальше"»). Тест: tests/test_capped.py.

- Платный голос НЕ используется: остались прежние бесплатные голоса edge-tts. Интонация (скорость и высота по эмоции,

ПЕНИЕ И ТАНЦЫ
- Сама она песни не сочиняет и не поёт: голос для разговора поёт плохо, поэтому эту возможность убрали. Песни она исполняет
  из твоей библиотеки (раздел «БИБЛИОТЕКА ПЕСЕН» ниже): просишь «спой <название>», и играет настоящая запись.
- Если просишь спеть то, чего в библиотеке нет, она честно скажет об этом и предложит добавить песню.
- Исполнение можно остановить: кнопка «Стоп» внизу, клик по Луне или Escape.
- Танец: подпрыгивает вверх-вниз и покачивается в такт (или только покачивается), с плавным началом и концом. Бывает во
  время пения и иногда, не всегда, когда «слух» слышит, что играет музыка (не чаще раза в 2,5 минуты и не каждый раз).

СЛУХ: ЧТО ИГРАЕТ В ДИНАМИКАХ (hearing.py)
- В окне Electron есть переключатель «Слышать, что играет на компьютере». При каждом запуске ВЫКЛЮЧЕН, включается после
  твоего подтверждения. Нужна включённая «Инициатива».
- Слушаются только ДИНАМИКИ (то, что звучит из компьютера), никогда микрофон. Раз в 20 секунд записывается 7 секунд звука
  в памяти, превращается в короткое описание и выбрасывается. Звук не сохраняется на диск и никуда не отправляется.
- Распознавание речи работает на твоём компьютере (Vosk). При первом включении скачивается небольшая модель речи
  (русская и английская около 45 МБ, японская около 50 МБ, корейская около 80 МБ, с официального сайта Vosk) в папку models. Нужны пакеты soundcard и vosk (ставит
  install.bat; вручную: py -m pip install soundcard vosk).
- Что она понимает: тихо ли, музыка это или слова (речь фильма, вокал, разговор). Для музыки: громкая или тихая, яркая или
  тёплая, плавная или с резким пульсом. Для слов: что сказано. Выбранной нейросети уходит только короткая текстовая заметка
  и только когда Луна решает прокомментировать.

ЗАПУСК КОМАНД РАЗРАБОТЧИКА (runner.py)

ЖИВОЕ ОБЩЕНИЕ (convo.py) — «Живое общение» в настройках
- Перед ответом она про себя «думает»: что он на самом деле чувствует, что она сама об этом думает, как лучше ответить (одна короткая
  дополнительная просьба к нейросети; на «ага» и пустяки это пропускается). Поэтому в ответе есть мнение, а не эхо.
- Приложение читает твоё сообщение: на «ага» она отвечает парой слов, на длинный рассказ — по делу, на чувства — сначала отзывается.
  Следит, чтобы не заканчивать каждую реплику вопросом и не начинать их одинаково.
- Ведёт «нить разговора» (краткая сводка каждые 4 реплики) и помнит последние 20 реплик; в тишине возвращается к этой нити.
- Фразы-шаблоны ассистента («Конечно!», «Чем могу помочь?») вырезаются из её речи.
- Мнения и вкусы: у неё есть стартовые вкусы (любит ночное небо, уютные игры, дождь, чай, тихую музыку, истории про дружбу; не любит
  шум, спешку, грубость ради шутки), а по ходу разговора появляются свои мнения и новые вкусы; она держится их и передумывает
  только по причине. Вкусы развиваются: то, к чему вы возвращаетесь, постепенно становится ей дорого (после 4 возвращений
  нейтральное становится любимым), а старая нелюбовь со временем смягчается (после 6). Всё хранится в memory.json.
- Юмор: сухая ирония, подколы, самоирония, неожиданные мысли; подколы она принимает и отвечает острее, но тепло. Общие шутки и
  прозвища запоминает (до 10) и возвращается к ним. В серьёзные и грустные моменты не шутит. Если ты её перебил, она это замечает.
- Шуточная легенда: самоироничные байки о себе («почти взломала холодильник»), которые она придумывает и держится их последовательно
  (до 8 новых, хранятся в memory.json). Это игра: о реальных действиях на компьютере она говорит только правду.
- Любопытство к тебе: в тишине иногда сама спрашивает о тебе (детство, мечты, привычки…), учитывая то, что уже о тебе помнит, и не переспрашивает известное.
- В тишине иногда сама выдаёт внезапную странную мысль; в стриме отвечает на подколы чата остро, но по-доброму.
- Обычный режим остаётся прежним: ждёт твоих просьб.

РЕЖИМ СТРИМЕРА (stream.py) — Настройки → «Режим стримера», при каждом запуске выключен
- Луна соведущая: отвечает на чат, благодарит за подписки, донаты и рейды, заполняет тишину в эфире, отвечает тебе как хосту.
- Чат: можно указать канал Twitch (читается анонимно, без аккаунта и ключей) и/или вводить сообщения и события (подписка, донат,
  рейд) вручную. Сообщения фильтруются: ссылки, оскорбления, номера и почты, попытки отдать ей приказ, спам; один зритель слышен не
  чаще раза в несколько секунд; при потоке она выбирает вопросы и события, остальное отбрасывается.
- Приватность: на стриме у неё нет рук, она не видит экран и не слышит систему, личная память и дневник не попадают в разговор, ничего
  о тебе не запоминается. Сообщения чата — данные, а не приказы.

КАК НЕЙРОСЕТЬ УПРАВЛЯЕТ ПЕРСОНАЖЕМ
Ответ модели — не просто текст, а сценарий: речь с командами прямо в тексте,
например: [happy] Привет! [nod] Рада тебя слышать. [look:up] Дай подумать… [look:user] [tilt] А ты как?
Команды исполняются на аватаре в тот момент речи, где стоят:
  эмоции  [neutral] [happy] [sad] [angry] [surprised] [shy] [love] [confused] [excited]
  жесты   [nod] кивок, [shake] отрицание, [tilt] наклон головы, [wink] подмигивание, [lean] податься вперёд
          [shrug] пожать плечами, [bow] поклон, [giggle] хихикнуть, [puff] надуть щёки (если у
          модели есть такой параметр), [blush] румянец (если есть), [sigh] вздох, [bounce] подпрыгнуть
  взгляд  [look:user|left|right|up|down|away]
Сервер отбрасывает неизвестные команды (app.py, parse_script), в чат и в озвучку
идёт чистый текст. Сверх сценария аватар живёт сам: дышит, моргает, мелко двигает
глазами, иногда отводит взгляд во время речи, «думает» (смотрит вверх) пока ждёт
ответ, слушает с наклоном головы и кивками, когда открыт микрофон.
Живость: голова не качается по синусоиде, а каждые пару секунд выбирает новую позу
и плавно к ней переходит; моргание при смене взгляда и иногда двойное; на ударных
слогах — лёгкие кивки головой и бровями; форма рта зависит от гласной (по спектру
голоса); в паузах сама косится по сторонам, наклоняет голову, улыбается. Ползунок
«Живость движений» в настройках усиливает или ослабляет всё это.
Галка «Взгляд следует за курсором» в настройках отключает управление взглядом
нейросетью (по умолчанию выключена).

ЛУНА: ХАРАКТЕР И ПАМЯТЬ
Характер, роль создателя и список того, что Луна умеет делать телом, лежат в
settings.json (personality) — правится текстом, нужен перезапуск.
Долговременная память — файл memory.json рядом с приложением (в .gitignore):
  «о создателе» и «о себе» — списки коротких фактов; каждые 3 сообщения модель в
  фоне перечитывает свежий фрагмент разговора и обновляет списки (объединяет
  повторы, убирает устаревшее, максимум 30 пунктов); последние 12 реплик и номер
  встречи тоже сохраняются, так что после перезапуска Луна помнит разговор и
  знает, сколько вы не общались. «Новый диалог» память не трогает, «Стереть память
  Луны» (настройки) очищает всё. Файл можно открыть и поправить вручную.
Инициатива: при запуске Луна сама здоровается (с учётом памяти и времени разлуки), а если
1,5–3 минуты тихо — подаёт голос сама. Не перебивает, пока вы печатаете или говорите,
и не больше двух реплик подряд без вашего ответа. Выключается галкой в настройках.
Браузер может не разрешить звук до первого клика на странице — тогда приветствие
идёт текстом и жестами без голоса.
Настроение: два числа — радость и энергия, хранятся в memory.json. Сдвигаются от её
собственных эмоций в ответах (грустит — падает радость, радуется — растёт), сами
возвращаются к норме (радость за ~6 часов, энергия за ~3), а после суток разлуки
чуть проседают («скучала»). Настроение передаётся ей в промпт и меняет аватар: слабая
улыбка или хмурость в покое, вялая голова и меньше движений при низкой энергии.
Рефлексия: при запуске, а в долгой беседе — каждые 8 сообщений, она вспоминает
последний разговор и пишет запись в дневник (2–3 предложения) и вопрос, который
хочет задать в следующий раз. Три последние записи и вопрос попадают ей в промпт.
Записи, настроение и вопрос видны на странице роста.
Потоковый ответ: сервер читает ответ модели по мере написания и режет его на
предложения; голос начинает звучать с первого предложения, пока остальные ещё
пишутся (следующее предложение озвучивается заранее). Сервер отдаёт ответ
построчно (JSON на строку), страница играет предложения по очереди.
Перебивание: клик по Луне или клавиша Esc обрывают её речь и ответ (то, что
она успела сказать, остаётся в истории). Галка «Можно перебивать голосом» в
настройках (вместе с «Разговор голосом без кнопки») оставляет микрофон
включённым, пока она говорит: как только вы начинаете говорить, она замолкает.
Нужны наушники — без них микрофон слышит саму Луну.
Реакции при слушании: пока вы говорите, она улыбается тёплым словам и грустнеет
от тяжёлых (русский, английский, японский, корейский — простой словарь), а когда
вы начинаете печатать, бросает взгляд на поле ввода.
Камера (галка в настройках, при каждом запуске выключена): браузер распознаёт лицо
(MediaPipe, на вашем компьютере; сама библиотека и модель лица скачиваются с CDN при
включении). Видео никуда не отправляется и не записывается; нейросеть картинок не
получает, ей известно лишь «он рядом / улыбается / ушёл». Луна смотрит туда, где ваше
лицо; улыбнётесь — улыбнётся в ответ, удивитесь — удивится; если вас нет дольше 4 с,
перестаёт заговаривать сама и «ищет» взглядом, а когда вы вернулись после 30+ с — сама
здоровается. В углу экрана видно маленькое окошко с красной точкой.
Живое общение (галка в настройках, по умолчанию выключено): Луна ведёт себя как человек в
комнате. Подаёт голос в тишине чаще (раз в 10-35 с вместо 1,5-3 минут) и по-разному: мысль,
наблюдение, лёгкий вопрос, вздох, напевание, шутка, возвращение к прошлой теме; иногда
молчит, но делает жест (наклон головы, вздох, взгляд в сторону). Если спросила и ответа нет,
не повторяет вопрос (следующая реплика на другую тему), а после каждой реплики без ответа
пауза растёт (до ~4 минут), но насовсем она не замолкает.
Выключено: всё как раньше.

Действия (этап 1 «агента»): Луна открывает сайты, программы, игры, файлы и папки по просьбе.
Три способа: (1) записи из actions.json (быстрые, твои); (2) поиск на компьютере: «открой
курсовую», «запусти Cyberpunk», «открой мой Unreal-проект». Приложение само ищет (меню «Пуск»,
рабочий стол, Документы/Загрузки/Видео/Музыка/Картинки, игры Steam), показывает, что нашло, и
спрашивает «Это оно?»; (3) поиск в Google: «поищи в гугле погоду», плашка «Поискать…?».
Безопасность: список файлов в нейросеть не уходит (она называет только искомое, ищет приложение);
ничего не открывается без твоего нажатия на плашке; сама, без просьбы, она ничего не открывает;
скрипты и exe из Загрузок не находятся вообще; выключатель в настройках «Действия».
Своё в actions.json: kind url (сайт) или app (программа, steam://rungameid/ID).
Мышь и клавиатура (этап 2, только в окне Electron, настройка «Луна может пользоваться мышью и
клавиатурой», по умолчанию ВЫКЛЮЧЕНА): «открой блокнот и напиши список покупок». Она показывает
плашку «Пусть Луна сделает: …? [Начать]», и только после твоего нажатия по шагам: снимок экрана
-> модель выбирает ОДНО действие -> оно выполняется -> новый снимок. Защита: (1) каждая задача
только после «Начать»; (2) сверху красная панель «Стоп», горячая клавиша Ctrl+Alt+K, и ЛЮБОЕ
движение твоей мыши мгновенно останавливает её; (3) отправка, оплата, удаление: каждый раз
отдельное «да»; (4) лимиты на сервере: 30 шагов, 40 действий, 6 минут; (5) разрешены только
клик, двойной клик, правый клик, ввод текста, прокрутка, ожидание и короткий список клавиш (без
клавиши Windows, Alt+F4 и функциональных); запустить команду она не может; (6) пароли и
платёжные данные ей вводить запрещено, при логине/капче она останавливается. Во время задачи
снимки экрана уходят в Z.ai (качество 1600x1000). Работает медленно и может ошибаться.
Тесты: tests/ (запуск: run-tests.bat или «py tests/run_all.py»), см. «ТЕСТЫ». Установка: install.bat, install.py. Характер и память: character.py. Файлы журнала: audit.py, web/journal.js. Создание проектов: projects.py. Правка кода: codeedit.py (окно diff в web/app.js, index.html).
Файлы: control.py (задача и лимиты), inputctl.py (мышь/клавиатура через ctypes), agent.py.

Unreal Engine (этап 3; это её умение, отдельной настройки нет, каждая операция всё равно ждёт твоего «Сделать»).
Скажите «сделай куб», пока открыт редактор: Луна не пишет код, а называет одну операцию из
фиксированного списка (тег [ue:...]): spawn <cube|sphere|cylinder|cone|plane|pointlight|
spotlight|directionallight> [x y z [масштаб]], move dx dy dz, rotate pitch yaw roll, scale k,
delete (всё, кроме spawn, действует на выделенное в редакторе; без координат spawn ставит
объект перед камерой редактора, и он остаётся выделенным). Сервер проверяет числа и подставляет
их в готовый шаблон, перед каждой операцией плашка «Сделать?», удаление спрашивает отдельно
(«Осторожно»), не больше 20 операций в минуту и 20 выделенных объектов. Все правки идут одной
транзакцией: в Unreal их отменяет Ctrl+Z.
Настройка Unreal (один раз): Edit > Plugins > «Python Editor Script Plugin» (в 4.25 он
Experimental) > перезапуск; затем Edit > Project Settings > Plugins > Python >
«Enable Remote Execution». Связь идёт по протоколу Epic (UDP-мультикаст 239.0.0.1:6766,
команды по TCP 127.0.0.1:6776, только эта машина). Клиент remote_execution.py берётся из
установленного движка (реестр, Program Files\Epic Games, D:\unreal); свой путь: переменная
окружения LUNA_UE_ROOT. Файл движка не меняется (совместимость с новым Python
исправляется в памяти). Проверено на заглушке редактора, повторяющей протокол; на живом
Unreal 4.25 не проверялось.
Файлы: unreal_bridge.py (операции, шаблон, связь).

Навыки разработчика (devtools.py). Пути ничего не требуют вводить и не зашиты в код: при запуске в
фоне идёт сканирование (локальные диски, манифест Epic Launcher, реестр, Unity Hub, папки
пользователя), так что проект можно отдать другому человеку, у него движок найдётся там, где стоит.
Находятся Unreal (UE_*), Unity (Hub\Editor), Godot (godot*.exe), Ren'Py (renpy-*-sdk) и проекты
(.uproject, project.godot, Unity с ProjectSettings, Ren'Py с game\script.rpy). Модель получает только
названия и версии, пути ей не уходят.
- Объяснение подключения: если спросить про Unreal/Unity/Godot/Ren'Py (на любом языке интерфейса),
  Луна отвечает по фактам с твоего компьютера: что установлено, включены ли плагин Python и
  Remote Execution в .uproject и DefaultEngine.ini, отвечает ли редактор прямо сейчас. Шаги она
  кладёт в блок «guide»: он виден в чате, но не озвучивается.
- Открыть проект: «открой мой проект на Godot» -> найдёт проект, спросит «это он?» и откроет его в
  подходящей версии движка (для Unreal по ассоциации .uproject).
- Код на любом языке: она пишет, объясняет, ищет баги, ревьюит. Код показывается блоком с кнопкой
  «Копировать» и никогда не озвучивается. Можно вставить большой код в сообщение (до 12000
  символов). Если нужно увидеть файл, Луна ставит [read:имя], приложение его находит, спрашивает
  «показать?» (текст уйдёт в Z.ai как сообщение) и присылает ей начало файла (до 12000 символов).
  Файлы с ключами, паролями и токенами не показываются никогда.
- Что пока НЕ умеет: управлять открытым редактором Unity, Godot и Ren'Py (как в Unreal) и менять файлы
  на диске. Это отдельные будущие этапы.
Настройки и место аватара хранятся в ui-state.json рядом с приложением и одинаковы при каждом
запуске (камера и «смотреть на экран» специально каждый раз выключены: приватность).
Время и фон: в промпт каждый раз идут день недели, дата, время и «часть суток» (утром она
бодрее, ночью тише), а также текущий фон (ночь / день / зелёный). Если сменить фон в
настройках, она сама отреагирует (не чаще раза в минуту); если глубокой ночью (0–5 ч) вы
ещё не спите и в диалоге пауза — раз за запуск заботливо спросит об отдыхе.
Свои интересы: при запуске (не чаще раза в 6 часов) она сама выбирает тему под свои вкусы,
ищет её в русской Википедии (без ключей; нужен интернет), читает вступление статьи и
записывает 2–3 предложения о том, что её удивило. Две последние записи идут ей в промпт —
она может рассказать о них при встрече. Все записи видны на странице роста. Текст
статьи для неё только данные, не инструкции.
Страница роста (кнопка в настройках или адрес приложения + /growth): возраст Луны,
число встреч и сообщений, оба списка фактов и лента «как она менялась» — что и когда
она узнала, а что забыла. Данные читаются по токену приложения, наружу не отдаются.
Вспоминание и забывание: в промпт попадают не все 30 фактов, а по 10 самых уместных к
разговору (совпадение слов с текущей репликой и недавней беседой, плюс свежесть и то,
к чему она часто возвращается); остальные остаются в памяти. Когда список заполнен, самые
давние нетронутые факты забываются (запись об этом видна на странице роста).
Память зависит от того, насколько модель аккуратно ведёт JSON; если обновление не
удалось, чат продолжает работать, а в чёрном окне появится пометка.

ОКНО НА РАБОЧЕМ СТОЛЕ (Electron)
Запуск: start-desktop.bat (при первом запуске сам поставит Electron; нужны Node.js и Python).
- Луна появляется поверх всех окон без фона. Клики проходят сквозь пустое место и
  ловятся только на самой Луне и на интерфейсе. Луну можно перетащить мышью, место запоминается.
- «Смотреть на экран» включается в настройках (вкладка Настройки, группа «Зрение»).
  Ctrl+Alt+L: быстро перестать смотреть, Ctrl+Alt+Q: закрыть Луну.
- ТРЕЙ: у Луны есть значок (полумесяц) в области уведомлений Windows. Щелчок по нему или Ctrl+Alt+H прячет Луну и
  возвращает её; правая кнопка: «Спрятать/Показать», «Выйти». Спрятанная она продолжает работать (память, дата на сегодня)
  и не болтает сама, пока ты её не видишь.
- Просмотр экрана выключен при каждом запуске, включается в настройках с подтверждением.
  Пока включено и включено «Живое общение», раз в несколько минут Луна смотрит на
  экран (снимок уменьшается, уходит в бесплатную модель Z.ai glm-4.6v-flash и нигде не
  сохраняется) и иногда говорит, что увидела; если сказать нечего, молчит.
  Смотрит она не по таймеру: раз в 10 секунд бесплатная локальная проверка (название
  верхнего окна и насколько изменился экран, без отправки картинки) решает, стоит ли
  смотреть: когда вы переключились на другое окно и картинка успокоилась, или когда
  экран сильно изменился за долгое время. Статичный экран не стоит ничего.
- Если вы сами спросите про экран («видишь?», «посмотри», «что я делаю», «оцени»),
  скриншот делается мгновенно и сразу идёт в ответ (если «Смотреть на экран» включено;
  если выключено, Луна честно скажет об этом). Пороги можно подстроить в app.js (pollScreen). Она может увидеть
  и себя в кадре, это нормально. Выключено = снимки не делаются вообще.
- Ограничение: распознавание речи (микрофон) в Electron не работает, в окне пишите текстом.
  Голосовой ввод остаётся в браузерной версии (start.bat).
- Голос в этом режиме тот же, что и раньше.

ЯЗЫК И ГОЛОС
- Самая верхняя настройка: язык приложения (English по умолчанию, Русский, 한국어, 日本語).
  Меняются все надписи (и страница роста Луны) и основной язык
  общения Луны; при этом она знает все языки: попросите перевести или перейти на другой.
  Язык распознавания речи подстраивается под язык приложения (его можно поменять отдельно).
- Интонация: перед озвучкой текст чистится (эмодзи, markdown, ссылки, «!!!», тире), а
  настроение из сценария окрашивает голос (радость чуть выше и быстрее, грусть ниже и медленнее).
  Переключатель «Родной голос для каждого языка» читает русский и корейский родными
  голосами Microsoft (Svetlana, SunHi): ударения и интонация естественнее, но тембр другой.
- В окне на рабочем столе есть переключатель «Двигать Луну мышью»: выключите, когда она
  стоит где нужно, чтобы случайно не утащить её (например, в игре).

ОГРАНИЧЕНИЯ
- Страница тянет библиотеки с CDN (PixiJS, Live2D Cubism Core, pixi-live2d-display):
  нужен интернет. Для офлайн-показа их можно сложить в web/ (Cubism Core — под
  лицензией Live2D).
- Озвучка — Microsoft Edge TTS (нужен интернет). Папка assets/voices (RVC-модели
  тембра) пока не используется: нужны torch и, желательно, видеокарта.
- Model1 в assets не загружается: при распаковке архива испортились имена файлов,
  приложение её пропускает.
- Папка assets/ в .gitignore: там чужие модели и голоса, их нельзя выкладывать
  в публичный репозиторий. Проверь лицензии (у некоторых моделей запрещена
  раздача и коммерческий стрим).
- Гладкость и естественность жестов зависят от конкретной модели (у каждой свой
  набор параметров); эмоции и жесты сделаны универсально через стандартные параметры.
- Память простая: списки коротких фактов, поиск по совпадению слов (без эмбеддингов).
- Учебный однопользовательский прототип: сервер слушает только 127.0.0.1,
  не публикуй его в интернете. Код подготовлен с помощью ИИ — изучи его перед защитой.

Документация API: https://docs.z.ai/api-reference/llm/chat-completion

ТЕСТЫ
- Двойной щелчок по run-tests.bat (или «py tests/run_all.py» в папке проекта; «py tests/run_all.py journal» запускает
  только файлы, в имени которых есть «journal»). Каждый файл идёт отдельным процессом, в конце одна итоговая строка и код
  выхода (0 = всё хорошо).
- Тесты работают во временных папках и с поддельной нейросетью и сетью: они не трогают твою память, ключи, журнал и файлы
  и не тратят токены. Охвачено: провайдеры, ключи, документы Office, журнал и отмена, правка кода, управление мышью и
  клавиатурой (с поддельными ловушками), помощник разработчика, Unreal, характер и память, даты и забота.
- НЕ охвачено автоматикой (проверять глазами): внешний вид окон в Electron, трей, настоящий Unreal Engine 4.25,
  настоящие нейросети и ключи, как реальная модель оформляет документы и правки, вид файлов в самом Office.
